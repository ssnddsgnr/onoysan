# VISION_Архитектурная Спецификация — Data Mobility & Reporting Engine

Этот документ описывает слой **Data Mobility & Reporting** (Мобильность данных и отчетность). Мы проектируем мост между прошлым пользователя и его будущим, обеспечивая легкий «переезд» в Sana и профессиональную презентацию финансовых данных во внешнем мире.


--------------------------------------------------------------------------------

Статус: Final Specification

Роль: Импорт исторического контекста и генерация брендированных аналитических документов.

Принцип: «Ваши данные принадлежат вам». Полная свобода входа и выхода без потери смыслов.


--------------------------------------------------------------------------------

# 1. Слой импорта: «The Onboarding Bridge»

Переход из других инструментов (Excel, CoinKeeper, YNAB, банковские выписки) должен быть бесшовным. Sana не просто загружает цифры, она **интерпретирует** их.

## **Умный парсинг:**

Специализированный AI-агент анализирует структуру загруженного CSV/Excel файла.

## **Маппинг смыслов:**

Система предлагает пользователю сопоставить старые категории с новыми **Конвертами** и **Кошельками**.

*Пример:* «Я вижу в твоем старом файле категорию 'Жратва'. Давай привяжем её к нашему конверту 'Еда'?»

**Историческая целостность:** Транзакции записываются в Ledger с сохранением их оригинальных дат. Ledger помечает их как `imported`, чтобы Nostradamus мог учитывать их для анализа долгосрочных трендов.


--------------------------------------------------------------------------------

# 2. Архитектура воркера: `sana-report-worker`

Для генерации тяжелых документов используется отдельный изолированный бинарный процесс. Это гарантирует, что создание PDF-отчета на 100 страниц не замедлит чат с ИИ.

## **Async Processing:**

Backend ставит задачу в RabbitMQ → Report Worker подхватывает её → Генерирует файл → Складывает в S3 → Дирижёр отправляет ссылку пользователю.

## Форматы:

**PDF (По умолчанию):** Для презентации, налогов или личного архива.

**Excel/CSV (По запросу):** Для тех, кто хочет покрутить данные в сводных таблицах.


--------------------------------------------------------------------------------

# 3. Прецизионная отчетность (Targeted Extracts)

Sana уходит от концепции «одной общей выписки». Пользователь может запросить отчет по любому срезу данных через семантический запрос.

**Гранулярность:** * *«Сделай PDF только по Проекту А за последние 3 месяца»*.*«Выгрузи все траты на ремонт машины в CSV»*.*«Подготовь выписку для налоговой по доходам самозанятого»*.

*«Выгрузи все траты на ремонт машины в CSV»*.

*«Подготовь выписку для налоговой по доходам самозанятого»*.

**Контекст:** Отчет включает не только суммы, но и те самые **Заметки**, которые пользователь оставлял, а также метаданные (какой агент подтвердил транзакцию).


--------------------------------------------------------------------------------

# 4. Визуальный стандарт и Брендинг

Каждый документ, выходящий из Sana, является носителем эстетики и профессионализма сервиса.

**Branded Templates:** PDF-файлы используют фирменную типографику, минималистичный дизайн и четкую структуру (инфографика, диаграммы P&L, сводки по налогам).

**Trust Factor:** Брендированный отчет выглядит как документ из премиального банка, что повышает доверие при его предъявлении партнерам или финансовым институтам.


--------------------------------------------------------------------------------

# 5. Безопасность и жизненный цикл

**Temporary Storage:** Сгенерированные документы хранятся в защищенном S3-буфере ограниченное время (например, 24 часа), после чего физически удаляются.

**Data Privacy:** Отчеты генерируются на лету. В системе не хранятся «готовые» файлы, что исключает утечку всей истории через один взломанный линк.

**Encryption:** Все передаваемые файлы шифруются.


--------------------------------------------------------------------------------

# Почему это важно:

Слой экспорта и импорта закрывает цикл доверия. Пользователь знает, что его данные не «заперты» внутри. Он может легко войти в систему со своим багажом и так же легко получить профессиональное подтверждение своей финансовой состоятельности для внешнего мира.
