# 1. Философия: Архитектура Адаптеров

Бизнес-логика Sana (Ledger, Tax Engine, Nostradamus) не должна зависеть от конкретных внешних API. Мы строим систему, где замена LLM или поставщика данных — это вопрос смены конфигурации.

## 1.1. Паттерн Фабрики (The Factory Pattern)

В коде ядра запрещено использование SDK вендоров напрямую. Ядро обращается к **Фабрике Адаптеров**, которая возвращает реализацию абстрактного типажа (Rust Trait).

**Поток вызова:**

**Core:** Запрашивает адаптер через `AdapterFactory::get_ai_provider()`.

**Factory:** Инжектирует API-ключи из Vault.

**Result:** Возвращает структуру, реализующую типаж `ModelProvider`.

Управляет доступом к LLM.

```
#[async_trait]
pub trait ModelProvider: Send + Sync {
    // Backend передает только данные (Context Payload).

    async fn invoke_agent(&self, agent_id: AgentType, payload: ContextPayload) -> Result<AgentResponse, AiError>;

```

## 2.2. Режимы работы Фабрики

Фабрика выбирает провайдера (Gemini/Claude/Groq) в зависимости от типа задачи (Fast Loop / Slow Loop).

## 2.3. Middleware: PII Sanitizer

Перед передачей данных в адаптер, слой `Sanitizer` вырезает из `Context Payload` любые PII (телефоны, email), заменяя их на токены `[REDACTED]`.

## 2.4. Когнитивная Логистика: Протокол «Static Prompts, Dynamic Data»

Бэкенд не формирует текстовые промпты. Он отвечает исключительно за сбор и доставку **Контекста** (данных). Сами инструкции (System Prompts) закешированы внутри Агентов.

Адаптер запрашивает курс у нескольких источников (Binance, CoinGecko) и вычисляет среднее, отбрасывая экстремумы, прежде чем вернуть значение Ядру.

# 5. Инфраструктура: Управление Секретами

**Secret Injection:** API-ключи инжектируются в процесс из HashiCorp Vault при старте.

**Hot Reload:** При смене ключа в Vault, Бэкенд пересоздает адаптеры без остановки сервиса.

# Резюме

**Backend** в этой схеме выступает как эффективный диспетчер. Он знает **«Кому»** передать данные (благодаря команде Дирижёра) и **«Что»** передать (Контекст), но не знает **«Как»** именно Агент будет обрабатывать эти данные, так как промпты инкапсулированы в AI-слое.
